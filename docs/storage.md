# 数据存储目录

Windows 新安装默认把数据库和业务文件存放在 `%LOCALAPPDATA%\invoice-management\Data`。应用偏好、识别服务设置、MCP 令牌和目录配置仍由 `%APPDATA%\invoice-management` 管理。显式指定独立 user-data-dir 的测试/开发进程使用该独立配置目录下的 `data`，不访问正常安装的数据。

已有版本若在旧配置目录中存在 invoice.db，会继续使用旧位置，不会在升级时自动搬动。到“设置 → 数据”查看实际路径，使用“恢复默认目录”迁移至系统默认位置，或“更改目录”选择自定义位置。

## 更换位置

1. 保存当前修改，等待识别和其他文件操作完成。
2. 选择空的数据文件夹，检查原生确认框中的目标路径。
3. 点击“迁移并重启”。应用生成 SQLite 一致性副本，复制原件和垫付附件，校验哈希后切换目录配置，再重启加载新位置。

原目录不会删除，旧备份仍在原位置。迁移后它是旧副本，不会继续同步；日常使用以设置中显示的新路径为准。恢复默认位置时，若默认位置已有本应用的旧数据，其文件夹会另存为 `Data.previous-<随机标识>`，再载入从当前自定义目录复制的最新数据。

迁移不会把目标目录中已有的其他文件合并进来，不支持直接选择磁盘根目录、当前业务目录的上级/子目录、配置根目录或程序安装目录。目标空间、权限、校验或目录配置写入失败时，不切换到未验证的数据；已复制的安全副本可能保留。

## 外置磁盘与恢复

自定义目录不可访问、数据库缺失或目录配置损坏时，应用会明确提示并停止打开，不会悄悄创建一个空数据库。优先重新连接原磁盘或恢复原目录。目录指针是配置目录中的 `storage-location.json`，需要手动修复时，应先关闭应用，并确认目标目录同时包含正确的 invoice.db 和 invoice-files；不要直接修改正在使用的数据库。

正常备份、跨电脑转移仍建议使用“创建备份 / 恢复备份”，而不是只复制 invoice.db。业务备份包含发票、项目、标签、识别结果、垫付及收回明细和凭证，不包含程序偏好或 MCP 访问令牌。
